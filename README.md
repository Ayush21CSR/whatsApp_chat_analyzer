WhatsApp Chat Analyzer

A Streamlit-based interactive dashboard for analyzing WhatsApp chat exports.
It provides detailed insights into group or individual chats, including statistics, sentiment, activity patterns, word clouds, emoji usage, and more.

🚀 Features

📊 Basic Statistics → Total messages, words, media shared, links.

😊 Sentiment Analysis → Positive/Negative/Neutral distribution using NLP.

📈 Activity Timeline → Monthly & daily message trends.

👥 Most Busy Users → Active users & their contributions.

☁️ Word Cloud → Visualization of most frequent words.

📝 Most Common Words → Tabular & graphical view.

😀 Emoji Analysis → Emoji usage distribution.

🔥 Activity Heatmap → Day & time activity patterns.

🎯 Complete Analysis → One-click full report.

Tech Stack

Python 3.8+

Streamlit → UI framework

Pandas → Data preprocessing

Seaborn & Matplotlib → Visualizations

NLTK / VADER → Sentiment Analysis
